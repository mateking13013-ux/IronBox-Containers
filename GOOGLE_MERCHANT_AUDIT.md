## 1. Product Feed (the deliverable Google needs)

A Google-spec product feed has been generated and is committed to the site.

| | |
|---|---|
| **Feed file** | `public/product-feed.xml` |
| **Public URL** | **https://ironboxcontainers.com/product-feed.xml** |
| **Format** | RSS 2.0 with the Google `g:` namespace (`http://base.google.com/ns/1.0`) |
| **Items** | 119 of 120 (1 excluded — see §4) |
| **Regenerated by** | `npm run feed` (also runs automatically on every `npm run build`) |

### How to register it in Merchant Center
1. Merchant Center → **Products → Feeds → Add primary feed**.
2. Country: **United States**, Language: **English**.
3. Method: **Scheduled fetch**.
4. Feed URL: `https://ironboxcontainers.com/product-feed.xml`
5. Set a daily fetch schedule. Google will pull updates automatically on each deploy.

### Fields included per item
`g:id`, `g:title`, `g:description`, `g:link`, `g:image_link` + up to 10 `g:additional_image_link`,
`g:availability`, `g:price` (USD), `g:sale_price` (when set), `g:condition` (new/used/refurbished),
`g:brand`, `g:mpn`, `g:identifier_exists=no`, `g:google_product_category`, `g:product_type`,
and `g:shipping` (US / Freight).

## 2. Adjustments made to the site for Merchant compliance

- **On-page Product structured data (JSON-LD) now matches the feed.** On `/products/[slug]`:
  - Image URLs are now **absolute** (`https://ironboxcontainers.com/...`) instead of relative — Google requires absolute image URLs.
  - Added `itemCondition` (New/Used/Refurbished as schema.org URLs).
  - Added `priceValidUntil` so the Offer is valid for rich results.
  - Price, currency (USD) and availability already matched the feed — consistency prevents "mismatched value" disapprovals.
- **Currency is 100% USD** across the catalog, checkout, cart, and price filters (no Rand anywhere).
- **Business identity is US-based** in schema/meta: `addressCountry: US`, region `TX`, Decatur TX geo, US phone `+1 816 255 7461`.
- **Feed auto-builds**: `package.json` `build` runs the feed generator before `astro build`, so the XML is never stale.

### Still to configure inside Merchant Center (account-level, not code)
1. **Shipping settings** — these are freight/quote items, so set account-level shipping (flat rate or "contact for quote" where allowed) under *Tools → Shipping and returns*. The feed declares `US / Freight / 0.00` as a placeholder; your account shipping overrides it.
2. **Return policy** — add a matching return policy in *Shipping and returns* (Google reads this separately from the website page).
3. **Business information & verification** — verify and claim the website URL; add business name, address, and customer-service contact.
4. **Tax** — configure US sales-tax settings (destination-based).
